# ทายคำลอย (FloatWord)

แอป Android ที่มีไอคอนลอยทับเกม/แอปอื่น กดแล้วเปิดตัวช่วยหาคำ

## วิธีสร้างไฟล์ .apk
**วิธีที่ 1 Android Studio**: File > Open เลือกโฟลเดอร์นี้ รอ Sync > Build > Build APK(s)
ไฟล์อยู่ที่ app/build/outputs/apk/debug/app-debug.apk

**วิธีที่ 2 ไม่มีคอม (GitHub)**: อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้น GitHub repo ใหม่
แท็บ Actions > Build APK > Run workflow แล้วโหลดไฟล์จาก Artifacts

## วิธีใช้
1. ติดตั้ง .apk (อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก)
2. เปิดแอป กด "เปิดตัวช่วยลอย" อนุญาต "แสดงทับแอปอื่น" แล้วกดอีกครั้ง
3. ไอคอน 🔍 จะลอยอยู่ ลากย้ายได้ แตะเพื่อเปิดหน้าต่างหาคำ ลากแถบด้านบนหน้าต่างเพื่อย้าย กด ✕ เพื่อย่อกลับเป็นไอคอน
4. ปิดเต็มๆ: แตะการแจ้งเตือน "ทายคำลอยกำลังทำงาน" หรือกด "ปิดตัวช่วยลอย" ในแอป

หมายเหตุ: มือถือบางยี่ห้อ (Xiaomi, Oppo, Vivo, Huawei) ต้องเปิดสิทธิ์ "หน้าต่างลอย/ทำงานเบื้องหลัง" ในการตั้งค่าแอปเพิ่มเติม
